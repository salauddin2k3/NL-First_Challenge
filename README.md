## Typescript এ, Interface এবং Type এর মধ্যে পার্থক্য। 

TypeScript-এ `interface` এবং `type` — উভয়ই অবজেক্টের টাইপ ডিফাইন করতে ব্যবহৃত হয়। তবে কখন কোনটি ব্যবহার করা উচিত, তা জানা অত্যন্ত জরুরি।

---

### 🔥 Interface এবং Type-এর মূল পার্থক্য——

এই দুটি কীওয়ার্ড কীভাবে কাজ করে, তার প্রধান পার্থক্যগুলো নিচে তুলে ধরা হলো:

| **Features** | **Interface** | **Type** |
| :--- | :--- | :--- |
| Declaration merging | একই নামের একাধিক ইন্টারফেস থাকলে তারা একটি ইন্টারফেসে মার্জ হয়ে যায়। | Type মার্জ হয় না। তবে একই নামের একাধিক টাইপ লিখলে error দেয়। |
| Ability to create new types | শুধুমাত্র অবজেক্ট বা ক্লাসের টাইপ ডিফাইন করতে ব্যবহৃত হয়। | যেকোনো ধরনের টাইপ ডিফাইন করতে পারে: অবজেক্ট, প্রিমিটিভ, ইউনিয়ন, ইন্টারসেকশন, ফাংশন সিগনেচার, টুপল ইত্যাদি। |
| Extension | `extends` কীওয়ার্ড ব্যবহার করে অন্য ইন্টারফেস বা টাইপকে এক্সটেন্ড করে। | `&` অপারেটর ব্যবহার করে অন্য টাইপ বা ইন্টারফেসকে এক্সটেন্ড করে। |
| Implementation | Classএ `implements` করা যায়। | অবজেক্টের টাইপ ডিফাইন করলে Class এ `implements` করা যায়। |


* অবজেক্টের টাইপ ডিফাইন করার সময় ইন্টারফেস ব্যবহার করা যেতে পারে। এবং ইউনিয়ন, ইন্টারসেকশন, প্রিমিটিভ টাইপ বা এই ধরনের জন্য Type ব্যবহার করা যেতে পারে।



---



### 🔥 TypeScript-এ Union এবং Intersection এর উদাহারণ——

TypeScript–এর দুটি গুরুত্বপূর্ণ ফিচার হলো union এবং intersection টাইপ।
* Union মানে — একাধিক টাইপের যেকোনো একটি।
* Intersection মানে — সব টাইপের প্রপার্টি একসাথে।

---

### 🔵 Union Type Example (A বা B)

`let userId: string | number;

userId = "A-101"; // ✔
userId = 101;     // ✔`
