# ইন্টারফেস (Interface) এবং টাইপ (Type) এর মধ্যে পার্থক্য কী?

TypeScript-এর টাইপিং জগতে, `interface` এবং `type` (টাইপ অ্যালিয়াস) উভয়ই অবজেক্টের কাঠামো সংজ্ঞায়িত করতে ব্যবহৃত হয়। তবে কখন কোনটি ব্যবহার করা উচিত, তা জানা অত্যন্ত জরুরি।

---

## 🔥 Interface এবং Type-এর মূল পার্থক্য

এই দুটি কীওয়ার্ড কীভাবে কাজ করে, তার প্রধান পার্থক্যগুলো নিচে তুলে ধরা হলো:

| বৈশিষ্ট্য | **ইন্টারফেস (Interface)** | **টাইপ অ্যালিয়াস (Type Alias)** |
| :--- | :--- | :--- |
| **ডিক্লেয়ারেশন মার্জিং** | **স্বয়ংক্রিয়ভাবে একত্রিত (Merge) হয়।** একই নামের একাধিক ইন্টারফেস থাকলে তারা একটি সিঙ্গেল ইন্টারফেসে মার্জ হয়ে যায়। | **মার্জ হয় না।** একই নামের একাধিক টাইপ অ্যালিয়াস ঘোষণা করা হলে ত্রুটি (error) দেয়। |
| **নতুন টাইপ তৈরির ক্ষমতা** | শুধুমাত্র **অবজেক্টের কাঠামো** বা ক্লাসের চুক্তি সংজ্ঞায়িত করতে ব্যবহৃত হয়। | **যেকোনো ধরনের টাইপ** সংজ্ঞায়িত করতে পারে: অবজেক্ট, প্রিমিটিভ (যেমন: `string`), ইউনিয়ন, ইন্টারসেকশন, ফাংশন সিগনেচার, টুপল ইত্যাদি। |
| **এক্সটেনশন (Extension)** | `extends` কীওয়ার্ড ব্যবহার করে অন্য ইন্টারফেস বা টাইপকে এক্সটেন্ড করে। | `&` (ইন্টারসেকশন) অপারেটর ব্যবহার করে অন্য টাইপ বা ইন্টারফেসকে এক্সটেন্ড করে। |
| **ইমপ্লিমেন্টেশন (Implementation)** | ক্লাসে `implements` করা যায়। | অবজেক্টের কাঠামো সংজ্ঞায়িত করলে ক্লাসে `implements` করা যায়। |

### 💡 সংক্ষিপ্ত ব্যবহারিক গাইডলাইন

* **ইন্টারফেস ব্যবহার করুন** যখন আপনি একটি **অবজেক্টের কাঠামো** সংজ্ঞায়িত করছেন এবং চান যে এটি **মার্জযোগ্য** হোক (যেমন: লাইব্রেরি বা থার্ড-পার্টি মডিউলে টাইপ যোগ করা)।
* **টাইপ ব্যবহার করুন** যখন আপনি একটি **ইউনিয়ন** বা **ইন্টারসেকশন** টাইপ তৈরি করছেন, অথবা যখন আপনি একটি প্রিমিটিভ টাইপের জন্য একটি অ্যালিয়াস তৈরি করতে চান (যেমন: `type ID = string | number`)।

# 🔗 ব্লগ পোস্ট ২: TypeScript-এ Union এবং Intersection Types

ইউনিয়ন এবং ইন্টারসেকশন টাইপগুলি TypeScript-এর সবচেয়ে শক্তিশালী বৈশিষ্ট্যগুলোর মধ্যে অন্যতম, যা আমাদের জটিল ডেটা মডেলগুলি নির্ভুলভাবে তৈরি করতে সাহায্য করে।

---

## ১. ইউনিয়ন টাইপ (Union Type) - `|` (OR)

ইউনিয়ন টাইপ একাধিক টাইপের মধ্যে **"অথবা" (OR)** সম্পর্ক স্থাপন করে। এটি দ্বারা সংজ্ঞায়িত একটি ভেরিয়েবল এই টাইপগুলোর **যেকোনো একটি মান** ধারণ করতে পারে।

### উদাহরণ: নমনীয় প্যারামিটার তৈরি করা
এই উদাহরণে, `id` প্যারামিটারটি হয় একটি `string` বা একটি `number` হতে পারে।

```typescript
type ID = string | number;

function printUserId(id: ID) {
  // টাইপ ন্যারোইং এখানে জরুরি
  if (typeof id === 'string') {
    console.log(`String ID: ${id.toUpperCase()}`);
  } else {
    console.log(`Number ID: ${id * 100}`);
  }
}

printUserId(12345);    // Number ID: 1234500
printUserId("TXN-901"); // String ID: TXN-901
// printUserId(true); // ❌ ত্রুটি
